# Changelog

All notable changes to Weesite will be documented in this file, starting with release 1.0, when the [design brief](docs/design/brief.md) is complete. Until then, [docs/plan/TRACKER.md](docs/plan/TRACKER.md) and the git history record what changed.

The format will follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
