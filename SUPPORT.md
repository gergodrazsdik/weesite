# Support

Weesite is a personal open-source project with one maintainer. There is no guaranteed support.

- **Questions and problems:** open an [issue](https://github.com/gergodrazsdik/weesite/issues/new/choose). Check the [brief](docs/design/brief.md), [deploy guide](docs/deploy.md) and existing issues first.
- **Security problems:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **Contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

When you ask about your own deployment, leave out hostnames, Azure IDs, secrets and full OpenTofu plans.
