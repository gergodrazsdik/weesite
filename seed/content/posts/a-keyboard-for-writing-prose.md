I write code all day on the same keyboard, and for years I wrote prose on it too, in the same editor, with the same habits. Lately I've been trying to separate the two, and it has made writing noticeably easier.

![Close-up of the keys of a computer keyboard](/media/116c3f9b1f40-keyboard.jpg "The keyboard on my desk")

## Different work, different habits

Code is written in bursts: a few lines, a test, a correction, a jump to another file. Prose wants a long, steady pace. When I wrote blog posts in my code editor, I kept doing code things: going back to fix every word, reformatting, checking something in another window.

So I changed a few small things:

- Prose goes in a plain text editor with no file tree, no linter and no extensions.
- Line wrapping on, line numbers off.
- No going back until the first draft is finished. Typos stay where they fall.

## The keyboard itself

I didn't buy a new one, though I was tempted. What helped was paying attention to how I type. Writing prose, I rest my hands more, look at the screen less and think in sentences instead of shortcuts. A keyboard is just a keyboard; the mode I'm in is what matters.
